## 检查方法

`scripts/audit_release.py` 读取暂存对象和已有历史对象，检测本地路径、私有项目标识、常见供应商凭证格式、URL 凭证、非空模板密钥、私有文件路径、已配置本地密钥的原值匹配，以及 PNG 文本／EXIF 元数据。发现项仅输出文件名、行号与类型，不回显凭证。

`scripts/release_check.py` 同时检查课程结构、发布文件类型与未公开功能路由。检查只作本地发布辅助，不能证明所有文字的版权状态，也不能保证识别所有形式的个人信息；新增文件或再次暂存后应重新运行。
