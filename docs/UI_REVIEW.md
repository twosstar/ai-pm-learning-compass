# 学习工作台 UI 改版记录 · 2026-10-22

## 方向与范围

用户反馈上一版配色太深、界面有模板化的 AI 产品观感，并希望加入渐变。当前使用近白画布，在页头加入蓝紫至暖白的柔和渐变，续学卡片采用浅蓝紫渐变，进度条使用低饱和冷色过渡；渐变只作局部点缀，阅读区域继续保持白底和清晰文字。沿用现有 HTML/CSS/JavaScript，使用 ui-design-system 的六项界面审查与 frontend-design 的布局、排版、自我审视方法。没有增加远程字体、图片服务或组件依赖。

## 六项审查

| 维度 | 原问题 | 本次调整 |
|---|---|---|
| 视觉层级 | 深色顶部和介绍占用过多空间，课程被推到首屏下方 | 缩成轻量页头，继续学习与真实进度并列，桌面首屏可见课程 |
| 配色 | 大面积深青令人感觉沉重；纯色浅蓝又显得像通用模板 | 近白底色；页头和续学卡局部轻渐变；正文、知识卡片仍为白底和高对比文字 |
| 排版 | 英文栏目标签和重复说明较多，课程要点缺少主次 | 去掉装饰性英文眉题；课程标题、知识摘要、状态分层；详情继续按需展开 |
| 间距 | 首页多个纵向大块打断浏览 | 收紧头部和控制区；搜索与练习方向在桌面同排 |
| 组件 | 课程路径缺少便捷导航，首次进入只有禁用续学按钮 | 桌面侧栏提供十个可跳转模块；空状态可直接开始第一节，已学习者恢复原位置 |
| 现代感 | 更像展示页，读课与找课之间切换费力 | 固定轻量侧栏、清晰课程行、浅色图解，少量本地 SVG 线条插图 |

## 交互与内容

- 侧栏模块跳转会清除搜索、展开对应模块并聚焦模块标题，不创建练习或调用模型。
- 首次开始只打开第一节知识阅读；恢复练习继续使用原题、草稿和已保存评价。
- 切换智能学习／概念地图时分别记录滚动位置，首次打开概念地图从顶部开始。
- 已读、已评练习、流程完成与掌握度分别记录，不把浏览当作掌握。
- 阅读核心仍为三条要点、职责／步骤图、短例子和面试要会；深入解释默认折叠。
- 课程和知识点的教材来源面板不展示；参考元数据保留供内容维护，不将隐藏来源等同于版权许可。
- 这里是响应式网页；没有新增原生 App、账户同步或多人数据隔离。
